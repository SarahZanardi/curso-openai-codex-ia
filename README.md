# OpenAI Codex — Landing Page

Landing page moderna e responsiva para divulgar o curso gratuito **OpenAI Codex: Desenvolvimento de Aplicações e Automação com IA**, da Analytics & Data Specialist.

> Uma página simples, rápida e pronta para publicar no GitHub Pages.

## ✨ O que você encontrará

- Hero section com chamada para inscrição no curso
- Conteúdo do curso organizado em cards
- Seções de público, metodologia, benefícios e instrutora
- Layout adaptado para desktop, tablet e celular
- Menu mobile e rolagem suave
- Animações discretas ao entrar na viewport
- SEO básico, Open Graph, favicon e HTML semântico
- Botões conectados diretamente à página oficial do curso

## ▶️ Executar localmente

Não há dependências ou processo de build.

1. Baixe ou clone este repositório.
2. Abra `index.html` no navegador; ou use o **Live Server** no VS Code.

## 🚀 Publicar no GitHub Pages

1. Abra **Settings → Pages** no repositório.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch `main` e a pasta `/(root)`.
4. Clique em **Save** e aguarde o GitHub gerar o endereço público.

## ✏️ Personalizar

Para trocar o endereço do curso, substitua a URL `share.minicoursegenerator.com` nos links de `index.html`.

Para alterar cores, espaçamentos ou tipografia, edite as variáveis no início de `style.css`.

Os links de LinkedIn, GitHub, Política de Privacidade e Termos de Uso estão marcados com `#` em `index.html` e podem ser atualizados quando as URLs definitivas estiverem disponíveis.
