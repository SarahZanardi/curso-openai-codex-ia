# Curso OpenAI Codex — Landing Page

Landing page responsiva para divulgar o curso gratuito **OpenAI Codex: Desenvolvimento de Aplicações e Automação com IA**, da Analytics & Data Specialist.

## Tecnologias

- HTML5 semântico
- CSS3 responsivo
- JavaScript puro

## Estrutura

```text
├── assets/
│   └── favicon.svg
├── index.html
├── style.css
└── script.js
```

## Executar localmente

Abra o arquivo `index.html` em qualquer navegador. Para uma experiência de desenvolvimento melhor, use a extensão Live Server no VS Code.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub e envie todos os arquivos deste projeto.
2. No repositório, abra **Settings > Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main`, a pasta `/(root)` e clique em **Save**.
5. Aguarde a publicação; o GitHub exibirá a URL pública da página.

## Alterar o link do curso

O link oficial aparece nos botões de acesso em `index.html`. Procure por `share.minicoursegenerator.com` e substitua a URL pelo novo endereço quando necessário.
